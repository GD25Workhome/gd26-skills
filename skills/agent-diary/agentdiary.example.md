# agentdiary

项目名单，住在日记目录里（`<diary_dir>/agentdiary.md`）。一节一个项目，`## ` 后面是名称，
下面用 `- 字段：值`。类型决定栏目：`company` → 公司日志，`personal` → 个人日志，`other` → 其它。
路径、别名可选：没写路径的项目只在归类时按名称、别名对上（如反复出现但找不到仓库的项目）。
