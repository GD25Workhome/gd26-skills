# 输出示例

下面把范围限制在「大唐袜业」这一个项目，用来看版式。默认运行会纳入同一工具下各项目、各次会话的日报，并先去重；内容冲突时先问，不写进示例。名单里没有路径的项目由技能自己判断栏目。本示例收窄到一个项目，所以对不上的内容进入待确认。

示例假定 `<diary_dir>/agentdiary.md` 里已有：

```markdown
## 大唐袜业
- 类型：company
- 部门：示例部门
- 路径：/absolute/path/to/datang-hosiery
```

本示例已收窄到当前项目，展厅等对不上该名称的内容进入待确认，不套用这个项目的类型。

## 输入

```markdown
# 1 流水日记
- [ ] 我需要一个 skills 来梳理今天的工作日志
## 1.1 大唐袜业
- 修正开发计划：统一编码的逻辑后置
- **行权限的逻辑梳理**（8:40）：

## 1.2 展厅商机
- [x] UI调整（11:30～13:45 ） 1.5H
```

# 扁平写法与别名（默认范围）

不限制范围时，日记常常没有项目分节，项目名写在条目里，且写法不统一。下面这份用来看归类、时间归一化和注释块。

示例假定 `<diary_dir>/agentdiary.md` 里已有：

```markdown
## 大唐袜业
- 类型：company
- 部门：示例部门
- 路径：/absolute/path/to/datang-hosiery
- 别名：袜业、袜业库
```

## 输入

```markdown
# 1 流水日记
- [ ] 我需要一个 skills 来梳理今天的工作日志
- （09：00～）大唐袜业
	- （09:00～11:30）本机跑起前后端，补初始化数据和菜单权限
	- [x] 修正开发计划：统一编码的逻辑后置
- （9:00～）袜业库迁移并发布
	- 把 tigshop-pre 导入新库。332 张表都在，逐表行数合计 8712
	- ～12:00，迁移完成。管理端和 C 端的 test 配置改到新库
	- [ ] 阅读迁移脚本，确认回滚路径
<!-- 非项目开发（技能 / 知识库脚手架等，不进周报）
- 给袜业仓库初始化 Project Cairn，并改 save-md-artifact
-->
```

要点：

- `袜业库迁移并发布` 对上了 `aliases` 里的「袜业库」，归大唐袜业。
- `（09：00～）大唐袜业` 只是容器，不单独成事项；全角冒号照读，时间给了没有自己时间的下级条目。
- `～12:00，迁移完成` 是子条目正文里顺带提到的钟点，不拆成新事项；`[x]`／`[ ]` 是这条事项的细节。
- 注释块按正文读入，里面的「非项目开发」标记照常生效。
