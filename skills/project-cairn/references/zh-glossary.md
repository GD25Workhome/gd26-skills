# 中文术语对照表

Project Cairn 自身词汇的固定英文 → 中文术语对照。用于以中文撰写项目文档（`AGENTS.md`、`LOG.md`、`ROADMAP.md`、知识专题文档）时保持用词一致，避免各项目独立初始化后因译者不同而漂移。也用于从中文模板写英文文档、或在中英文档之间保持术语一致时的固定映射。

| cairn (the name / imagery) | 路标石堆（不用"玛尼堆"） |
